## 🚀 **Getting Started**

### **Prerequisites**
- **Node.js 18+** and **Python 3.11+**
- **MongoDB Atlas** account (free tier sufficient)
- **API Keys** for AI services (OpenAI, Hugging Face, Spotify)

### **Quick Setup**
```bash
# Clone the repository
git clone https://github.com/RogueFoxOne/Museum-Of-Impossible-Things.git
cd Museum-Of-Impossible-Things

# Frontend setup
cd frontend
npm install
cp .env.example .env.local
# Add your API keys to .env.local
npm run dev

# Backend setup (separate terminal)
cd ../backend
pip install -r requirements.txt
cp .env.example .env
# Add your API keys and MongoDB URI to .env
python app.py

# Access the platform
open http://localhost:3000
```

### **Environment Configuration**
```env
# Database
MONGODB_URI=mongodb+srv://your_connection_string
DATABASE_NAME=gestaltview

# AI Services
OPENAI_API_KEY=your_openai_key
ANTHROPIC_API_KEY=your_claude_key
HUGGINGFACE_API_KEY=your_hf_key

# Spotify Integration
SPOTIFY_CLIENT_ID=your_spotify_client_id
SPOTIFY_CLIENT_SECRET=your_spotify_client_secret

# Authentication
NEXTAUTH_URL=http://localhost:3000
NEXTAUTH_SECRET=your_nextauth_secret

# Voice Processing
DEEPGRAM_API_KEY=your_deepgram_key

# Analytics
VERCEL_ANALYTICS_ID=your_vercel_id
```
